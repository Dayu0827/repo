iOS 6 · Stable release

CoolBooterAudioFix 1.0.2

Designed to address reported music stuttering on CoolBooter iOS 6 setups by disabling the AirTunes HAL plugin.

Compatibility: iOS 6.x (package dependency: iOS 6 only).

Package ID: org.dayuzou.airtuneshall-disable

Reported test: iPod touch 5 running iOS 6.1.3. Other devices and versions have not been verified.

iOS 7 · Experimental beta

CoolBooterAudioFix 1.0.3~beta1

Experimental iOS 7 package for community testing. It uses a separate package ID and is not an upgrade of the iOS 6 release.

Target compatibility: iOS 7.x (package dependency: iOS 7 only).

Package ID: org.dayuzou.airtuneshall-disable-ios7-beta

Not yet verified on physical iOS 7 hardware. Please test only if you have a reliable recovery method and have backed up the original plugin. Disabling this plugin may remove AirPlay output support. The package's installation, audio behavior, and rollback still need real-device testing.
